# Universal Multilingual — Release Notes v1.12.0

**Status:** **RELEASED** (GitHub Release) — production deployment separately authorized  
**Release version:** 1.12.0  
**Schema target:** **8** (unchanged)  
**Settings schema:** **2** (option-shape marker only; no DB migration)  
**Package:** `universal-multilingual-1.12.0.zip`  
**Previous release tag:** `v1.11.1` @ `cc4c8c012d987b09131e86962b9f5be4e753ea23`

This minor release ships **User Regional Preferences** and the optional **Floating Language Selector**, plus supporting docs. URL language remains the anonymous authority. Production (`biopentra.eu`) is not authorized by this release.

## Highlights

### Regional preferences

- Logged-in preferred language (`aiml_preferred_language` user meta).
- WordPress Profile **Regional Preferences** and WooCommerce My Account → Account details fields.
- Public API: `aiml_get_preferred_language`, `aiml_get_preferred_language_state`, `aiml_set_preferred_language`.
- Optional composition with Universal Multicurrency via `um_regional_preferences_*` hooks. No hard UMC dependency.
- Site-default fallback uses WordPress `WPLANG` (empty → `en_US`).
- Preferred language does **not** change the current URL render language.

### Floating language selector

- Optional visitor-facing edge control; **default off**.
- Left/right edge, top/center/bottom, code/name/globe collapsed modes, edge_pill/minimal/tab presets.
- Independent desktop/mobile visibility (same HTML; CSS hide).
- Progressive enhancement: language links work without JavaScript.
- Keyboard disclosure; no flags.
- Authenticated best-effort preference persist (`keepalive`) that never blocks navigation.
- No language cookie; anonymous cache contract unchanged.

## Upgrade notes (1.11.1 → 1.12.0)

1. Install `universal-multilingual-1.12.0.zip` (or use DEV bind mount at this tag).
2. Confirm `aiml_db_version` remains **8**.
3. Floating selector remains **Off** until you enable it in Settings.
4. Review Profile / My Account Regional Preferences if you use signed-in language preference.

## Known limitations

- Floating selector is opt-in (default Off).
- Preferred language is a preference, not a routing signal.
- No country flags.
- Future independent UMC currency edge control is out of this package.
