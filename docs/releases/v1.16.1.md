## Delete translation ("start over")

There was no way to clear a page's translation and begin again short of
emptying each segment by hand. The Translator Workspace toolbar now has a
**Delete translation** action:

- Behind a destructive confirmation.
- Removes **every** stored translation segment for the current post in the
  current language — machine, manually edited, reviewed, in-review — **and** the
  localized URL slug candidate, the localized route and its history for that
  language.
- The canonical WordPress post is never touched.
- After it runs the editor reloads empty and the localized URL panel resets.

Implementation: `WorkspaceService::delete_translation()` →
`Store::delete_object()` (a method that already existed but had no caller) and
`RoutePublicationService::purge_for_source_language()` (new, per-language
sibling of the existing `purge_for_source`). REST:
`DELETE aiml/v1/workspace/<id>/translation?language=<code>`, permission
`can_edit_post` (same as the other Workspace write routes).

Regression test:
`WorkspaceRestTest::test_delete_translation_removes_every_segment_and_the_slug`.
